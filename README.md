# Support Desk Copilot

An AI support-desk assistant built step by step to learn agentic AI engineering with Claude, LangChain, LangGraph and LangSmith.

Status: Stage 1 (raw API calls) in progress.

## Setup
1. Node 20+ is required.
2. `npm install`
3. `cp .env.example .env` and add your own `ANTHROPIC_API_KEY`. Never commit `.env`.
4. `npm run typecheck`

## Run a script
`npm run run -- experiments/stage-01/raw.ts`
